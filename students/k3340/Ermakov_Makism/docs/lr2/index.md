# Лабораторная работа 2

## Общая информация

Тема лабораторной работы: `Потоки. Процессы. Асинхронность`.

Цель работы: понять отличия между потоками, процессами и асинхронным выполнением в Python, а также сравнить эти подходы на вычислительной задаче и задаче параллельного парсинга веб-страниц.

## Структура лабораторной работы

Код лабораторной работы находится в папке `lr_2` и разделен на две части:

```text
lr_2/
├─ task_1/
│  ├─ threading_sum.py
│  ├─ multiprocessing_sum.py
│  ├─ async_sum.py
│  └─ run_all.py
└─ task_2/
   ├─ parser_common.py
   ├─ threading_parser.py
   ├─ multiprocessing_parser.py
   ├─ async_parser.py
   ├─ run_parsers.py
   └─ requirements.txt
```

## Содержание задач

| Задача | Содержание | Папка |
|---|---|---|
| Задача 1 | Подсчет суммы чисел от `1` до `10_000_000_000_000` с использованием `threading`, `multiprocessing` и `asyncio` | `lr_2/task_1` |
| Задача 2 | Параллельный парсинг HTML-страниц, извлечение `<title>` и сохранение результата в базу данных ЛР 1 | `lr_2/task_2` |

## Используемые подходы

В обеих задачах сравниваются три подхода:

| Подход | Инструмент | Особенность |
|---|---|---|
| Потоки | `threading` | Несколько потоков внутри одного процесса, общая память |
| Процессы | `multiprocessing` | Несколько независимых процессов, отдельная память |
| Асинхронность | `asyncio`, `aiohttp` | Один event loop и переключение задач в точках `await` |

## Итоговое сравнение

В первой задаче быстрее всего отработал `async/await`, затем `threading`, затем `multiprocessing`. Такой результат связан с тем, что сумма считается по формуле арифметической прогрессии, поэтому само вычисление занимает очень мало времени, а главным фактором становятся накладные расходы на запуск задач.

Во второй задаче быстрее всего отработал `async/await`, потому что парсинг веб-страниц является I/O-bound задачей. Программа в основном ожидает сетевые ответы и операции записи в базу данных, поэтому асинхронный подход хорошо использует время ожидания.
