# Лабораторная работа 1

## Общая информация

Тема лабораторной работы: `Реализация серверного приложения FastAPI`.

Выбранная предметная область: `тайм-менеджер`. Итоговое приложение позволяет:

- создавать задачи;
- задавать им описание, приоритет и дедлайн;
- вести учет затраченного времени;
- формировать ежедневные планы;
- группировать задачи по категориям и тегам;
- работать с пользователями, регистрацией и JWT-аутентификацией.

## Какие части включает ЛР 1

Выполнение лабораторной строилось поэтапно и опиралось на три практические работы:

| Работа | Содержание | Папка |
|---|---|---|
| Практика 1.1 | Базовое FastAPI-приложение и временная база данных | `lr_1/practice_1_1` |
| Практика 1.2 | PostgreSQL, SQLModel, связи и CRUD через ORM | `lr_1/practice_1_2` |
| Практика 1.3 | Alembic, `.env`, `.gitignore`, структура проекта | `lr_1/practice_1_3` |
| Лабораторная работа 1 | Итоговый серверный проект по теме тайм-менеджера | `lr_1/lab_1` |

## Почему отчет разбит на отдельные страницы

В методических указаниях было важно не только показать конечный результат, но и отразить, как именно проект развивался от простой версии к полноценному приложению.

Поэтому каждая работа вынесена в отдельную вкладку:

- сначала показана учебная версия с временной базой;
- затем переход к PostgreSQL и SQLModel;
- затем подключение миграций, `.env` и улучшение структуры;
- после этого описана финальная лабораторная работа.

## Что проверяется в ЛР 1

По требованиям задания итоговый проект должен содержать:

- не менее пяти таблиц;
- связи `one-to-many` и `many-to-many`;
- ассоциативную сущность с дополнительным полем;
- CRUD API;
- вложенное отображение связанных объектов;
- PostgreSQL;
- SQLModel;
- Alembic;
- типизацию входных и выходных данных;
- структурированный проект по папкам;
- для расширенной версии: регистрацию, JWT, аутентификацию и смену пароля.

Все эти пункты отражены в последующих страницах отчета.
