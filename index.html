Отчеты по лабораторным работам

Назначение сайта

Этот сайт подготовлен в формате GitHub Pages и используется как единый отчет по всем лабораторным работам по дисциплине web-программирования.

Сейчас на сайте размещены материалы по Лабораторной работе 1, в состав которой входят:

  • практическая работа 1.1;
  • практическая работа 1.2;
  • практическая работа 1.3;
  • итоговая лабораторная работа 1.

В дальнейшем сюда же будут добавляться разделы для следующих лабораторных работ. Для этого в навигации каждая лабораторная работа оформляется как отдельный блок со своими практиками и итоговой страницей.

Структура хранения материалов

В репозитории используются две разные структуры:

  • код лабораторных работ хранится в папках lr_1, lr_2 и далее;
  • сам MkDocs-сайт расположен в корне папки студента и собирает материалы по всем лабораторным работам в одном месте.

Текущая структура для первой лабораторной работы:

students/k3340/Ermakov_Makism/
├─ docs/
│  └─ lr1/
├─ lr_1/
│  ├─ practice_1_1/
│  ├─ practice_1_2/
│  ├─ practice_1_3/
│  └─ lab_1/
└─ mkdocs.yml

Такой подход удобен по двум причинам:

  • код и отчет не смешиваются;
  • при добавлении ЛР 2 достаточно создать новый блок страниц docs/lr2/ и новый пункт в mkdocs.yml.

Что содержится в отчете

Для каждой работы в отчете приводятся:

  • цель и постановка задания;
  • пошаговый ход выполнения;
  • важные фрагменты кода;
  • описание моделей данных;
  • список реализованных API-эндпоинтов;
  • настройка базы данных и миграций;
  • итог выполненной работы.

Для итоговой лабораторной работы отдельно включены:

  • все реализованные модели;
  • все эндпоинты;
  • код подключения к базе данных;
  • описание JWT-аутентификации и пользовательского функционала.

Локальный запуск отчета

Из корня репозитория:

source .venv/bin/activate
cd students/k3340/Ermakov_Makism
mkdocs serve

Локально сайт будет доступен по адресу:

http://127.0.0.1:8001

Порт 8001 выбран специально, чтобы не конфликтовать с запуском FastAPI-приложения на 8000.
